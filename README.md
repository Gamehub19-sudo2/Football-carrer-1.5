# Football Career 1.2

Jogo de carreira de futebol em HTML, com clubes brasileiros, ligas europeias e seleções.

## Como jogar
1. Abra `index.html` em um navegador moderno.
2. Jogue partidas para ganhar Fama.
3. Busque contratos e assine com clubes para receber bônus e salários por partida.
4. Treine para aumentar o Overall; cada treino custa R$ 1.000.

## Dificuldade nesta versão
- Vitórias e ganhos de Fama são mais difíceis.
- O dinheiro entra mais devagar.
- Treinar custa R$ 1.000.
- Clubes de divisões e ligas maiores exigem Fama e Overall mínimos. Por exemplo, Premier League exige 1.000 de Fama e Overall 86; seleções exigem 1.400 de Fama e Overall 91.

## Publicar no GitHub Pages
Envie `index.html` e `README.md` para a raiz do repositório. Depois, em Settings → Pages, habilite a publicação pela branch principal e pela pasta raiz.

O progresso fica salvo no armazenamento local do navegador. A lista de equipes é uma base do jogo e pode não refletir todos os participantes oficiais atuais.
